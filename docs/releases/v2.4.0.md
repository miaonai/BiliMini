## 更新

- 新增综合热门页，支持滚动加载、稍后再看和失败重试。
- 设置中可分别关闭投稿页、直播页的红点提示。
- 拖动栏目名前的三横条调整顺序，数字快捷键跟随已显示栏目的顺序。
- 可隐藏番剧、直播、历史、热门栏目，以及充电专属视频和稍后再看按钮。
- 支持调整弹窗宽度、自适应或手动 1–4 列，以及隐藏滚动条。
- 卡片显示播放量、弹幕数和时长；历史页支持分页、观看进度和观看设备图标。
- 修复筛选后翻页、快速切页时数据混入和顶栏晃动等问题。

## 下载与安装

- `BiliMini-v2.4.0-chrome.zip`：Chrome / Edge 扩展，解压后在扩展管理页开启开发者模式，选择“加载已解压的扩展”并选中包含 `manifest.json` 的目录。
- `BiliMini-v2.4.0-chrome.crx`：CRX3 签名安装包，仅适用于允许安装外部 CRX 的浏览器或受管理环境。Chrome 在 Windows / macOS 上通常不允许直接安装商店外的 CRX，请使用 ZIP 加载方式。
- `SHA256SUMS.txt`：两个下载文件的 SHA-256 校验值。

本发行版由 GitHub Actions 从 `v2.4.0` 标签构建。CRX 使用本仓库固定密钥签名，ZIP 包含同一公钥，两种安装方式使用相同扩展 ID；它们与原 Chrome / Edge 商店版本的 ID 不同，因此不会覆盖商店版本或自动迁移其设置。

本次发行资产面向 Chrome / Edge，不包含 Firefox 商店签名包。
