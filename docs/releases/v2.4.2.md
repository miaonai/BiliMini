## 下载与安装

- `BiliMini-v2.4.2-chrome.zip`：适用于 Chrome / Edge。解压后在扩展管理页开启开发者模式，选择“加载已解压的扩展”，并选中包含 `manifest.json` 的目录。
- `BiliMini-v2.4.2-chrome.crx`：CRX3 签名安装包，适用于允许安装外部 CRX 的浏览器或受管理环境。安装受浏览器策略限制，也可使用 ZIP 加载方式。
- `SHA256SUMS.txt`：两个下载文件的 SHA-256 校验值。

本发行版由 GitHub Actions 从 `v2.4.2` 标签构建。CRX 使用本仓库固定密钥签名，ZIP 包含同一公钥，延续现有 GitHub 版本的扩展 ID。GitHub 版与原 Chrome / Edge 商店版本分别安装，不会覆盖商店版本或自动迁移其设置。

本次发行资产面向 Chrome / Edge，不包含 Firefox 商店签名包。
