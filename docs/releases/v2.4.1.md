## 更新

- 新增视频卡片悬停发光边框和封面微缩效果，默认开启，可在设置中分别关闭。
- 新增悬浮快照预览，默认关闭。开启后支持自动轮播，或关闭自动预览后按鼠标横向位置切换画面。
- 预览延迟默认 800ms，可设为 0–5000ms；自动更新间隔默认 700ms，可设为 100–2000ms。设置自动保存。
- 预览期间隐藏封面上的播放量、弹幕数、视频时长、发布时间、推荐原因及历史观看进度，退出预览后恢复。
- 使用对应分 P 的快照和时长；无法获取快照时保留原封面。
- 修复隐藏的充电专属视频仍触发未读角标和投稿更新提示的问题。

## 下载与安装

- `BiliMini-v2.4.1-chrome.zip`：适用于 Chrome / Edge。解压后在扩展管理页开启开发者模式，选择“加载已解压的扩展”，并选中包含 `manifest.json` 的目录。
- `BiliMini-v2.4.1-chrome.crx`：CRX3 签名安装包，适用于允许安装外部 CRX 的浏览器或受管理环境。安装受浏览器策略限制，也可使用 ZIP 加载方式。
- `SHA256SUMS.txt`：两个下载文件的 SHA-256 校验值。

本发行版由 GitHub Actions 从 `v2.4.1` 标签构建。CRX 使用本仓库固定密钥签名，ZIP 包含同一公钥，延续 v2.4.0 的扩展 ID。GitHub 版与原 Chrome / Edge 商店版本分别安装，不会覆盖商店版本或自动迁移其设置。

本次发行资产面向 Chrome / Edge，不包含 Firefox 商店签名包。
